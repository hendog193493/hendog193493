Jarvis — Privacy Policy

Last updated 11 November 2026

Jarvis is a personal assistant application written and run by one individual for their own use. It is not a commercial product, it has no other users, and it has no company behind it. This policy describes what the application does with data accessed through Google APIs.

Who operates it

A single private individual, running the software on their own personal computer. There is no organisation, no team, and no third-party operator.

What data is accessed

  • Gmail messages (gmail.readonly) — message headers, subjects, bodies and attachment metadata from the operator's own mailbox, used to summarise mail, find deadlines, and build a task list.
  • Google Calendar events (calendar.readonly) — event times, titles and attendees from the operator's own calendars, used to understand their schedule.
  • Google Cloud Pub/Sub (pubsub) — used only to receive Gmail's own change notifications, so the application learns that new mail has arrived. No message content passes through Pub/Sub.

Where the data goes

Data is stored in a local SQLite database file on the operator's own computer and nowhere else. It is not uploaded to any server, not sent to any third party, not used for advertising, not sold, and not shared with anyone. There is no hosted backend; the application has no server component other than a local web interface reachable only by the operator's own devices over a private network.

Analysis and AI processing

Message text is analysed by a language model running locally on the operator's own computer. Content is not sent to an external AI provider.

What the application cannot do

The Google authorization is read-only. The application cannot send, reply to, delete, label, or otherwise modify mail or calendar entries with the scopes it requests.

Retention and deletion

Data persists in the local database until the operator deletes it. Deleting the application's data directory removes everything it has stored. Access can be revoked at any time at myaccount.google.com/permissions, which immediately and permanently ends the application's ability to read anything.

Limited Use disclosure

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent to the operator at the email address registered as the developer contact on the application's Google Cloud project.
